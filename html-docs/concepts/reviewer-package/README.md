# Homepage screenshots for email

Four actual public homepage captures, with no comparison overlay or admin controls:

| --- | --- | --- | --- |
| 01-minimal-motion.jpg | Minimal / Motion | JPEG | 1425 × 990px |

All four were captured from the deployed direct concept homepages using the same 1440×1000 desktop viewport override. The native screenshot tool captured the 1425× 990 client area. These are unedited screenshots, not composites or generated mockups. Assets/fonts were loaded; the A2 was rendered and playing, and the grid capture shows a gentle actual interaction state.

`arc-lab-homepages.zip` contains exactly the four named JPEGs, with no other files or directories. Its size is 373,368 bytes. Individual file sizes and hashes are recorded in `images.json`.
