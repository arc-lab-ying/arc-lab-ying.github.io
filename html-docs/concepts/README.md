# ARC Lab website concept comparison

Four complete static prototype sites now extend the approved landing-page directions through the same original 16 routes. The original website and the earlier individual root prototypes remain unchanged. This is local design review on `codex/website-redesign`, with no deployment or merge to main.

Open the [Boostlab Team comparison](http://127.0.0.1:8771/prototype-concepts.html?variant=boostlab&page=people.html). The floating arrows and unmodified Left/Right keys compare the same current page across all four concepts, including when focus is inside the concept. The URL retains `variant` and the optional allowlisted `page`. Native navigation stays inside each concept. The review controls appear only on localhost and are separate from the prototype pages.

| Concept | Design question | Complete site |
| --- | --- | --- |
| 01 · Minimal / Motion | Does oversized blue typography and a stationary animated A2 express the lab well? | [Minimal](../../prototypes/minimal/index.html) |
| 02 · ParentSquare-inspired | Does a familiar institutional layout with photography suit a traditional audience? | [ParentSquare](../../prototypes/parentsquare/index.html) |
| 03 · GrowthBook-inspired | Does a centered introduction and clear research overview strike the right balance? | [GrowthBook](../../prototypes/growthbook/index.html) |
| 04 · Boostlab-inspired | Can four visible research links make a playful hover grid useful as navigation? | [Boostlab](../../prototypes/boostlab/index.html) |

Each concept includes Home, Team, Publications, Research, all four research details, Join Us, the news archive and all six news articles. Original content, names, dates, external destinations, 27 publication records, supplied photographs and ARC/Technion marks are retained. The two restrained alternatives have no JavaScript animation. Minimal retains A2 autoplay with pause/play. Boostlab retains the interactive grid and keyboard-accessible native research links.

The complete-site [review record, route inventory and screenshots](full-sites/README.md) documents 64 successful HTTP routes, source/content parity, local references/fragments, and 56 desktop/phone browser views. The inactive Code and pending Scholar labels remain plain spans with readable contrast. Physical devices and non-Chromium browser engines were not tested; external scholarly/profile destinations were preserved rather than revalidated remotely.

References reviewed visually: [ParentSquare](https://www.awwwards.com/sites/parentsquare) and its [live site](https://www.parentsquare.com/); [GrowthBook](https://www.awwwards.com/sites/growthbook) and its [live site](https://www.growthbook.io/); [Boostlab](https://www.awwwards.com/sites/boostlab) and its [live site](https://boostlab.btgpactual.com/en). These are layout inspirations, not copied third-party branding or content.

Reusable original ARC vector geometry remains in `assets/prototypes/shared/`. The earlier landing-page screenshots and `qa.json` beside this README document the previous review stage; `full-sites/` contains the current complete-site evidence.
