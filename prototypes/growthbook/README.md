# ARC Lab · Concept 03 · Complete site

GrowthBook-inspired, restrained research overview design. The approved centered homepage and static building/knowledge diagram lead into a complete mirrored set of the existing website's 16 pages.

Preview: http://127.0.0.1:8771/prototypes/growthbook/

Buildless HTML/CSS; no scripts, package installation, framework, or build step. Keep this folder under the repository's `prototypes/` directory: it references the existing shared assets two levels up (three levels from news and research detail pages).

All existing page paths, source prose, publication records and external links, names, dates, profile labels, news tags, gallery images and placeholder captions are retained. The homepage keeps the approved hero and overview, followed by the full original manifesto and four foundation questions, five latest news items and a static three-image gallery. Original gallery images are shown together rather than in an automatically changing carousel. Research summaries are repeated from the corresponding source detail pages. All six news articles have the same shared navigation as the rest of this concept.

Navigation stays inside this prototype set. The supplied outlined ARC mark and official Technion image retain their proportions. CSS uses the existing local Inter variable font. The design adds no decorative motion. The homepage diagram is a schematic illustration, not a model of a particular real building.

Source checks and link results are recorded in the staging folder's `complete-site-checks.json`. Browser QA is delegated separately.
