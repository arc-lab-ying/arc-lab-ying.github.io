# Research Field — complete static prototype

Review: `http://127.0.0.1:8771/prototypes/boostlab/`

The approved off-white grid, four permanently blue research directions, original ARC wordmark and blue hover trail remain the homepage. Grid headers, editorial team profiles, year-linked publication records, research reading pages, and news layouts extend the same visual language through the complete site.

All 16 original routes are present: five root pages, four research detail pages, the news archive, and six news articles. All original main-content text, 27 publication records and their external destinations, profile names/links/photos, dates, the Unitree A2 image, and home gallery images/captions are preserved. The gallery changes only when a visitor selects a dot; it does not autoplay.

The source news articles had no shared navigation and their ARC Lab breadcrumb led to the news archive. This prototype supplies the shared navigation and directs the ARC Lab breadcrumb to the concept homepage.

Assets are referenced from the original repository `assets` directory. The supplied ARC/Technion marks and geometrically faithful reusable wordmark are retained. No framework, package installation, remote font, or build step is required. All primary navigation uses native links, works by keyboard/touch, and stays within this prototype. Hover effects are decorative; reduced-motion preferences remove transitions.

Validation: JavaScript syntax passed. Source audit found no missing source text/images/external destinations, broken local assets/routes/fragments, duplicate IDs, or routes escaping the concept. All 29 protected original/root-prototype files matched their pre-work hashes. Browser QA is delegated separately.
