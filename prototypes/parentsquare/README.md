# Institutional prototype — ParentSquare direction

Design question: can a clear, photograph-led institutional design feel welcoming while remaining comfortable for a traditional academic audience?

This complete static concept has 16 pages: the homepage, Team, Publications, Research, four research details, Join Us, the news archive and all six original news articles. The original page bodies, 27 publications, names, dates, profile links and publication destinations are retained. The approved split-photo homepage remains, with the full original About text, five original news entries and a static version of the original three-image gallery below it.

The shared header and footer, pale blue page headings, comfortable reading widths and understated numbered research list carry the homepage direction throughout. There is no JavaScript, decorative animation, external runtime or package dependency. Original content assets and original ARC/Technion marks are referenced from the repository asset directory. This is a review prototype; it does not alter or replace the original website.

Reference: https://www.parentsquare.com/ (via https://www.awwwards.com/sites/parentsquare). The reference informs its practical navigation, reassuring hierarchy and photographic storytelling; the institutional split layout deliberately gives a different comparison from the centered GrowthBook concept.
